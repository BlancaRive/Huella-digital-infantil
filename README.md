# Huella Digital Infantil

Blog educativo orientado a familias y docentes de preescolar sobre el uso crítico, responsable y pedagógico de las tecnologías en la primera infancia.

## Publicación
Este proyecto está preparado para GitHub Pages y no requiere hosting de pago.

## Fuentes principales
- UNICEF: Uso de la tecnología en la primera infancia.
- UNICEF Innocenti: Childhood in a Digital World.
- American Academy of Pediatrics: Early Childhood Development and Screen Time Toolkit.
